# دليل DaVinci Resolve 21

الملف الكامل (ملف واحد): `DaVinci_Resolve_21_Master_Guide.md`

- المصادر: `front.md` + `chapters/01.md ... 20.md` + `back.md`، والملف الكامل يُولَّد منها
- لإعادة البناء: `python3 davinci/build_guide.py`
- للقطات الشاشة: التقطها بـ Win+Shift+S واحفظها باسم المعرف داخل `img/` (مثل `img/SHOT-07-03.png`) ثم شغّل `python3 davinci/embed_shots.py`، وقائمة الناقص بـ `SHOTS.md`
- لتحميل فصل واحد فقط لـ Claude استعمل الملف المناسب من `chapters/` بدل الملف الكامل (حجمه نحو 1.6 MB)
