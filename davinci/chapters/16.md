## 1. ما الذي تربحه من الأتمتة وما حدودها

الأتمتة هنا تخدم ثلاثة أشياء: مشروع يبدأ بنفس الإعدادات كل مرة، وملفات تنظم بنفس القواعد، وتصدير (Deliver، وتسميه أنت ريندر) يثبت بالقياس لا بالنظر

الأتمتة لا تلون عنك: واجهة البرمجة (API) لا تنشئ عقدة ولا تحرك عجلة (القسم 4)، فالتلوين يبقى في الواجهة (الفصلان 8 و9)

> **قاعدة (السكربت يحمل ولا يبني):** ما تبنيه مرة واحدة بالواجهة (preset المشروع، preset الريندر، الشجرة الثابتة، ملف `.drx`) يحمله السكربت أو Claude المتصل ويدققه ويكرره، ولا يبنيه ◐ سياسة الدليل

- السكربت الخارجي وخادم MCP الأصلي (نسخة Studio فقط) ✔ (ملاحظات الإصدار 21.1: "Advanced scripting now requires DaVinci Resolve Studio"، وجدول مقارنة الميزات: Scripting API وAI Assistants في Studio)، وأنت تملك Studio
- Python 2 لم يعد مدعوما ✔ (سجل تغييرات الـ API)، وResolve 21.1 يشحن Python 3.14 الخاص به ✔ (القسم 3)
- إن لم ترغب في MCP فشغل السكربتات بنفسك من `Workspace > Console` أو `Workspace > Scripts`، أو اكتف بالجلسة بلا اتصال ◐ (قرار الدليل)

## 2. الجلستان: بلا اتصال ومتصلة

الدليل يشرح الحالتين منفصلتين ولا يخلطهما ◐ (قرار الدليل)، لأن كل حالة تعد بشيء مختلف

### 2.1 جلسة بلا اتصال (الحالة أ)

هي أي جلسة Claude لا ترتبط بـ Resolve عندك: محادثة عادية أو جلسة سحابية، فلا ترى جهازك ولا التايم لاين
- تستطيع: الشرح، ومراجعة لقطات الشاشة والقيم الملصقة، وكتابة السكربتات وفحص صياغتها بـ `python3 -m py_compile`، وتجهيز presets وملاحظات وقوائم فحص، وتشخيص من لقطة المقاييس ورسم العقد وإعدادات المشروع
- لا تستطيع: رؤية التايم لاين، أو تشغيل الـ API، أو التحقق من أي نتيجة
- كل حكم على نتيجة ريندر يحتاج إطارا تصدره أنت أو ناتج ffprobe ترسله، وإن شك Claude فعليه أن يسألك، ولا يعد أي بند ⚠ مفحوصا قبل أن تفحصه

> **خطأ شائع:** اعتبار `py_compile` ضمانا لعمل السكربت: هو يثبت سلامة الصياغة فقط، أما قبول Resolve للمفاتيح والقيم فلا يثبته إلا تشغيل السكربت على نسخة من مشروعك (فحص CHK-126)

الجدول التالي يلخص ما ترسله لهذه الجلسة (البروتوكول الكامل في الفصل 18):

| ما ترسله | كيف تلتقطه | ما الذي يفحصه Claude |
|---|---|---|
| ناتج `rs_diag.py` (JSON) | شغل السكربت (القسم 8.3) | النسخة والصفحة والمفاتيح وعدد العقد وأدواتها ◐ |
| لقطات `Project Settings` و`Deliver > Render Settings` | `Win + Shift + S` | حقول لا تستطيع الـ API ضبطها: المرمز وKey Frames وData levels وAudio Normalization (الفصل 12)؛ و`Playback frame rate` تقرأه الـ API ولا تكتبه |
| إطاران قبل وبعد عند نفس التايم كود | `ExportCurrentFrameAsStill` أو المعرض (Gallery) | أرقام محسوبة من الصورة لا انطباع |
| كتلة ffprobe وقياس الصوت | `rs_verify.py` أو الأوامر في `cmd.exe` | الوسوم والأبعاد والمعدل والصوت |
| نص Console عند الخطأ | نسخ النص من `Workspace > Console` | مفتاح خاطئ أو كائن فارغ أو صفحة غير مناسبة |

   - القيمة الافتراضية للإعداد على تثبيت جديد غير مذكورة في النصوص ⚠ (فحص CHK-022)، فاقرأها وسجلها

## 4. ما تستطيع الـ API وما لا تستطيع

الجدول مستخرج من ملف `.pyi` للإصدار 21.1.0 (بحث شامل في أسماء الدوال) ✔

| المجال | تستطيع | لا تستطيع |
|---|---|---|
| المشروع والتايم لاين | إعدادات المشروع والتايم لاين بقواميس (`GetSettings` و`SetSettings`)، وpresets المشروع، وتغيير التايم لاين الحالي (`SetCurrentTimeline`) | فتح Project Settings أو Preferences، وضبط `timelinePlaybackFrameRate` |

```python
# rs_verify.py - check a rendered Reel against the file contract of chapter 12 (plain Python, Resolve is not needed).
# NOT TESTED on your machine yet (tested here on Linux with a synthetic file). Needs ffprobe and ffmpeg on PATH.
# Usage: python rs_verify.py R01_Corniche_v01_1080x1920_25p_TEST.mp4 25/1
import json
import re
import subprocess
import sys

PATH = sys.argv[1] if len(sys.argv) > 1 else ""
FPS = sys.argv[2] if len(sys.argv) > 2 else "25/1"
VIDEO = {"codec_name": "h264", "profile": "High", "pix_fmt": "yuv420p", "width": 1080, "height": 1920,
         "color_range": "tv", "color_primaries": "bt709", "color_transfer": "bt709", "color_space": "bt709"}
AUDIO = {"codec_name": "aac", "sample_rate": "48000", "channels": 2}
MAX_MB = 300                  # the ceiling of Meta's API documentation, used here as a conservative limit
PEAK_LIMIT = -1.0             # dBTP


def run(cmd):
    return subprocess.run(cmd, capture_output=True, text=True).stdout


def probe(entries, select):
    out = run(["ffprobe", "-v", "error", "-select_streams", select, "-show_entries", "stream=" + entries,
               "-of", "json", PATH])
    streams = json.loads(out or "{}").get("streams") or [{}]
    return streams[0]


def loudness():
    p = subprocess.run(["ffmpeg", "-hide_banner", "-nostats", "-i", PATH, "-vn", "-af",
                        "ebur128=peak=true:framelog=quiet", "-f", "null", "-"], capture_output=True, text=True)
    text = p.stderr.split("Summary:")[-1]
    integrated = re.search(r"I:\s+(-?[\d.]+)\s+LUFS", text)
    peak = re.search(r"Peak:\s+(-?[\d.]+)\s+dBFS", text)
    return (float(integrated.group(1)) if integrated else None, float(peak.group(1)) if peak else None)


def main():
    if not PATH:
        print("usage: python rs_verify.py file.mp4 [fps, for example 25/1]")
        return 2
    v = probe(",".join(list(VIDEO) + ["r_frame_rate", "avg_frame_rate", "bit_rate"]), "v:0")
    a = probe("codec_name,sample_rate,channels,bit_rate", "a:0")
    size_mb = float(json.loads(run(["ffprobe", "-v", "error", "-show_entries", "format=size", "-of", "json",
                                    PATH]) or "{}").get("format", {}).get("size", 0)) / 1e6
    rows = [("video " + k, want, v.get(k)) for k, want in VIDEO.items()]
    rows += [("r_frame_rate", FPS, v.get("r_frame_rate")), ("avg_frame_rate", FPS, v.get("avg_frame_rate"))]
    rows += [("audio " + k, want, a.get(k)) for k, want in AUDIO.items()]
    bad = 0
    for name, want, got in rows:
        ok = str(want) == str(got)
        bad += not ok
        print("%-4s %-24s want=%-12s got=%s" % ("OK" if ok else "FAIL", name, want, got))
    ok = size_mb <= MAX_MB
    bad += not ok
    print("%-4s %-24s want<=%-10s got=%.1f" % ("OK" if ok else "FAIL", "size MB", MAX_MB, size_mb))
    print("info video bit_rate:", v.get("bit_rate"), "| audio bit_rate:", a.get("bit_rate"))
    integrated, peak = loudness()
    print("info integrated LUFS:", integrated, "(compare with your target, chapter 15)")
    ok = peak is not None and peak <= PEAK_LIMIT
    bad += not ok
    print("%-4s %-24s want<=%-10s got=%s" % ("OK" if ok else "FAIL", "true peak dBTP", PEAK_LIMIT, peak))
    print("RESULT:", "PASS" if not bad else "FAIL (%d)" % bad)
    return 1 if bad else 0


sys.exit(main())
```

**المتوقع:** سطر `OK` أو `FAIL` لكل حقل، ثم `size MB` و`true peak dBTP`، وينتهي بـ `RESULT: PASS` أو `RESULT: FAIL (n)`؛ وأي `FAIL` يعني أن الملف لا يطابق العقد، فأصلح الـ preset أو الوسوم (الفصل 12) وأعد الريندر باسم نسخة جديدة

# User Preferences presets are left out on purpose (the 21.1 stub has Export, but this script never touches them).
# NOT TESTED on your machine yet. Factory presets may refuse to export: every result is printed.
# The ".preset" suffix is only a label here: read what extension each group really gets (CHK-124).
import os
import re
import sys
import time

OUT = sys.argv[1] if len(sys.argv) > 1 else os.path.join(r"D:\Projects", "_backup", "presets", time.strftime("%Y%m%d_%H%M%S"))


def get_resolve():
    r = globals().get("resolve")
    if r is not None:
        return r
    import DaVinciResolveScript as dvr
    r = dvr.scriptapp("Resolve")
    if r is None:
        print("STOP: Resolve is not running or not fully loaded, not Studio, or External scripting is None")
    return r


def has(obj, name):
    names = dir(obj)                                            # dir(), never hasattr()
    return ("GetName" in names or "GetVersion" in names) and name in names     # sanity check first


def names_of(items):
    out = []
    for it in items or []:
        n = it if isinstance(it, str) else (it.get("Name") or it.get("PresetName"))
        if n:
            out.append(n)
    return out


def main():
    resolve = get_resolve()
    if resolve is None:
        return None
    proj = resolve.GetProjectManager().GetCurrentProject()
    if proj is None:
        print("STOP: no project is open")
        return None
    os.makedirs(OUT, exist_ok=True)
    groups = [("render", proj, "GetRenderPresetList", resolve, "ExportRenderPreset"),
              ("project_settings", proj, "GetProjectSettingsPresetList", proj, "ExportProjectSettingsPreset"),
              ("keyboard", resolve, "GetKeyboardPresetList", resolve, "ExportKeyboardPreset"),
              ("layout", resolve, "GetLayoutPresetList", resolve, "ExportLayoutPreset"),
              ("burnin", resolve, "GetBurnInPresetList", resolve, "ExportBurnInPreset")]
    ok = bad = 0
    for folder, owner, lister, exp_owner, exporter in groups:
        if not (has(owner, lister) and has(exp_owner, exporter)):
            print("skip", folder, "(not available in this build)")
            continue
        sub = os.path.join(OUT, folder)
        os.makedirs(sub, exist_ok=True)
        for name in names_of(getattr(owner, lister)()):
            path = os.path.join(sub, re.sub(r"[^\w.\- ]+", "_", name) + ".preset")
            done = bool(getattr(exp_owner, exporter)(name, path)) and os.path.exists(path)
            ok, bad = ok + done, bad + (not done)
            print("OK  " if done else "FAIL", folder, name)
    print("exported %d, failed %d -> %s" % (ok, bad, OUT))
    return ok, bad


result = main()

**المتوقع:** سطر `OK` أو `FAIL` لكل preset مع اسمه، وسطر `skip` لنوع غير متاح في نسختك، وينتهي بـ `exported N, failed M -> المسار`؛ وقد تفشل presets المصنع في التصدير
